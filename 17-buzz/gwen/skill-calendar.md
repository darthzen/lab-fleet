Load the google-workspace skill first.

Rick's standing rule: an action item becomes an event on `rick@theashfords.org` in `America/Chicago`. The event description carries everything needed to do the task: links, numbers, names, the source email or message. If Rick did not give a time, ask or leave it as all-day; do not invent one.

Check for conflicts with `get_events` before creating. Never move or delete an existing event unless Rick asks. Invite other people only when Rick asks.
